# 梅式指挥中心 - Dashboard

## 项目结构

```
lobster-dashboard/
├── public/
│   └── index.html
├── src/
│   ├── App.js
│   ├── components/
│   │   └── LobsterCard.js
│   ├── data/
│   │   └── lobsters.js
│   └── styles/
│       └── index.css
├── package.json
└── README.md
```

## 功能说明

- 8只龙虾可视化展示
- 产品小梅大卡片 + 3个小小梅子卡片
- 下方4只龙虾平铺
- 深色模式UI
- 点击卡片复制 `@龙虾名` 到剪贴板

## 部署

部署到 Render 平台，带基础HTTP鉴权。
